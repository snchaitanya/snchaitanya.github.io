# Strategy (the agent rewrites this file after every run)

Goal: at least $10/day of real, repeatable income, using the owner's skills
and existing assets, with as little of the owner's time as possible.

## Current focus (starting hypotheses, not yet tested)

1. **Paid bounties that match existing skills** - open-source issues with cash
   bounties (Algora, IssueHunt, Gitcoin-style GitHub bounties), data or
   Python/SQL tasks. Fast feedback: paid on merge.
2. **Short freelance gigs** in data quality, SQL, data pipelines, compliance
   reporting - favor fixed-price jobs that take 1-3 hours.
3. **Paid expert work** - expert-network calls, paid technical writing,
   paid reviews, AI-training/evaluation contract work for domain experts
   (finance, compliance, data engineering).
4. **Monetize assets already owned** - Cric Scout (sponsorships from local
   cricket clubs/academies, donations), the personal site (consulting page,
   affiliate links to tools actually used).
5. **Small digital products** - templates, checklists, SQL/data-quality kits
   sold on Gumroad or similar, built once and sold many times.

## Rules for picking opportunities

- Must be live right now, with a working link and a clear payout.
- Expected value per hour of the owner's time beats raw payout.
- Prefer things that compound (products, reputation, repeat clients) over
  one-offs once a few one-offs are working.
