Ledger Check

Data-quality, reconciliation and anomaly checks for your household finances — a mini CCAR for your bank, card and brokerage exports.

Your files never leave this device

  • No uploads. Files are read locally with the browser's File API and analysed in memory.
  • No network at all. The page's Content Security Policy sets connect-src 'none', so the browser itself blocks any attempt to send data — even by a bug in this code.
  • No storage. Nothing is written to cookies, localStorage or IndexedDB. Closing the tab, or pressing Clear everything, discards it all.
  • No third parties. No analytics, fonts, CDNs or trackers; three small scripts you can read: engine.js, app.js, sample.js.
  • Account numbers masked on screen and in exports by default.
How to verify this yourself
  1. Open your browser's developer tools → Network tab, then load a file. You will see no requests.
  2. Or save this page (and its four files) to your computer, disconnect from the internet, and open index.html. It works fully offline.
  3. Prefer a sanitised copy anyway? Most banks let you export only the columns you need — date, description, amount, balance.
